# Buyer Log — shared development instructions

Before changing this repository, read the short `AGENTS.md`; open only the relevant
section of the canonical `CLAUDE.md` when you need detail. Apply the performance tier
from `CLAUDE.md` §3.2 / `docs/PERFORMANCE_ACCEPTANCE.md` §0 to every update and new
module. Record the performance verdict and evidence in the PR template. These
rules apply in local and Cloud environments; do not replace them with a separate
tool-specific policy.
