# Animasyonlu satır seçimi önerileri

Her HTML tek dosyadır; internet, sunucu veya kurulum gerektirmez. Tarayıcıda açıp “Animasyonu oynat” düğmesine basın veya sol baştaki boş seçim alanına tıklayın.

1. **Akış — 01-akis.html:** 8 px tam yükseklikte şerit, merkezden açılma/kapanma. Yoğun tablolar için öneri.
2. **Kapsül — 02-kapsul.html:** 14 px alanda 6 px yuvarlatılmış çubuk, kısa yerleşme hareketi.
3. **Işık izi — 03-isik-izi.html:** 12 px alanda 3 px çizgi; seçim anında kısa ışık yayılımı.

Üçünde de gerçek checkbox semantiği, Boşluk tuşu, Shift ile aralık seçimi, başlıktan toplu seçim ve kısmi seçim, açık/koyu tema, animasyonu kapatma ve azaltılmış hareket desteği vardır. Animasyon sonludur, boşta döngü çalışmaz. Kayıtlar sentetiktir. Seçenekler henüz uygulamanın satır seçicilerini değiştirmez.

Chromium ile altı satır üzerinde seçim sayacı, Shift aralığı, kısmi başlık, tümünü seçme, klavye, animasyonun tamamlanması, tema ve azaltılmış hareket kontrol edildi; JavaScript hatası görülmedi.
