## Workload and sampling

Synthetic fixture: one order with two 300-unit IAS partials and a 400-unit production remainder; expanded to 1,000 independent orders / 3,000 output rows. Old approval=2020-01-01; Ex-Factory=2090-01-01; Retail=2090-03-12. Fixed seed=7. Input XLSX SHA-256 values are recorded in fixtures-sha256.json; all 24 measured runs were checked against the matching size and had identical source file bytes. The fixture generation is fully preserved in measure.cjs; source XLSX bytes are generated by the same installed xlsx dependency on both sides.

Initial sequence: 3 alternating Main/candidate pairs per size (3 rows and 3,000 rows), five repeated HTTP requests per server, then one real XLSX export. The initial larger XLSX candidate sample included a 3569 ms outlier. Instead of treating that as a pass, six same-Main A/A runs and three confirmation pairs in reversed candidate/Main order were collected. All raw observations, including the outlier, remain in initial.jsonl and noise-and-confirmation.jsonl. No p95 inference is made from three pairs.

Same-Main A/A repeated-export medians ranged 39.51–51.45 ms, XLSX 2307.84–2569.83 ms, and sampled RSS peaks 563056–600216 KiB. Candidate confirmation medians sit within that observed Main variability. CPU confirmation samples overlap (Main 346/349/364 ticks; candidate 343/354/378 ticks). Small first/repeated-request differences did not reproduce consistently across paired runs. No reproducible regression was established; no percentage tolerance or higher budget was introduced.

Data/behavior checks run on every process: 3 or 3,000 JSON and XLSX rows; production quantity=400; candidate approval is null and risk is YOK; Main retains its old approval and false VAR. Actual partials and source-order approval remain covered by the regression tests. Large JSON payload decreases from 5,999,762 to 5,973,762 bytes, consistent with removal of inherited dates. XLSX remains structurally readable with the same row count. Five repeated requests measure bounded reuse; RSS does not grow monotonically without bound. Every server is terminated in finally. Sampled RSS is not represented as a continuously observed absolute memory peak. Windows/SMB/native Electron timing is not asserted.
